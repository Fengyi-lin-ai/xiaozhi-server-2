# 小智语音助手服务器项目架构设计

## 一、项目概述

这是一个基于 Python asyncio 的智能语音助手服务器项目，支持 WebSocket 实时通信，提供语音识别 (ASR)、大语言模型对话 (LLM)、语音合成 (TTS) 等完整功能链路。

## 四、模块详细设计

### 4.1 VAD (语音活动检测)

```python
# core/providers/vad/base.py
class VADProviderBase(ABC):
    @abstractmethod
    def is_vad(self, conn, data) -> bool:
        """检测音频数据中的语音活动"""
        pass

# 实现：SileroVAD (models/snakers4_silero-vad)
```

**支持的后端**:
- `SileroVAD`: 本地 Silero 模型 (默认)

**关键参数**:
- `threshold`: 语音检测阈值 (默认 0.5)
- `threshold_low`: 低阈值 (默认 0.3)
- `min_silence_duration_ms`: 最小静音时长 (默认 200ms)

## 六、插件系统

### 6.1 插件类型

```python
class ToolType(Enum):
    NONE = 1              # 调用完工具后，不做其他操作
    WAIT = 2              # 调用工具，等待函数返回
    CHANGE_SYS_PROMPT = 3 # 修改系统提示词
    SYSTEM_CTL = 4        # 系统控制
    IOT_CTL = 5           # IoT 设备控制
    MCP_CLIENT = 6        # MCP 客户端
```

### 6.2 插件动作

```python
class Action(Enum):
    ERROR = -1      # 错误
    NOTFOUND = 0    # 没有找到函数
    NONE = 1        # 啥也不干
    RESPONSE = 2    # 直接回复
    REQLLM = 3      # 调用函数后再请求 LLM 生成回复
```

### 6.3 插件注册

@register_function(name="get_weather", desc="获取天气信息", type=ToolType.WAIT)
def get_weather(location: str):

## 七、关键技术特性

### 7.1 异步并发模型

- 基于 `asyncio` 的事件循环
- WebSocket 使用 `websockets` 库
- 线程池处理 CPU 密集型任务

### 7.2 音频处理

- 输入格式：Opus 编码 (16kHz, 单声道)
- 输出格式：Opus/PCM/WAV
- 流控机制：`audioRateController`

### 7.3 会话管理

- `session_id`: UUID 标识每次连接
- `device_id`: 设备唯一标识
- `client_id`: 客户端标识

### 7.4 安全认证

- JWT Token 认证
- 设备白名单
- 可选启用

### 7.5 声纹识别

- 支持多说话人识别
- 可配置相似度阈值
- 动态启用/禁用

## 十、总结

该项目是一个功能完整、架构清晰的智能语音助手服务器，具有以下特点：

4. **配置灵活**: 支持本地配置和 API 动态配置
5. **生产就绪**: 包含认证、日志、错误处理等完整功能
